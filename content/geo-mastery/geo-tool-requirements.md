# GEO 答案监测工具：页面需求与设计

## 一句话解释

一个面向非编程业务用户的单页 GEO 监测工具：把同一道问题交给 AI 独立回答 3 次，观察目标产品是否被提及、首次出现在哪里、三次回答是否稳定。本阶段为前端页面和模拟交互，为后续接入真实 API 预留接口。

## 适合谁

* 想了解 GEO 监测工具要做什么页面、每个页面有哪些功能的人。
* 需要把页面需求文档交给 Agent 生成的实操者。
* 想理解模拟交互和真实 API 接入之间区别的人。

---

## Part 1：工具定位

工具用于观察：当用户把同一道问题交给生成式 AI 多次回答时，目标产品是否被提及、首次出现在哪里、不同回答是否稳定。

固定配置：

| 项目 | 值 |
|---|---|
| 平台 | DeepSeek |
| 模型 | deepseek-v4-flash |
| 接口 | Responses API |
| 联网 | 接入后每次监测强制使用 web_search |
| 调用次数 | 每道启用问题固定 3 次 |

> 页面阶段结果必须明确标记为"模拟"，不得让用户误以为已来自真实互联网。

---

## Part 2：视觉方向

* 整体风格：专业、克制、清晰，适合医药企业内部培训
* 浅灰蓝色背景，白色内容卡片，深蓝色左侧固定导航
* 主操作蓝色，成功状态绿色
* 充足留白，避免密集卡片和过多装饰
* 禁止使用 emoji 作为功能图标
* 桌面端优先，窄屏下保持可用，不产生横向内容丢失

---

## Part 3：三个页面的整体导航

左侧导航包含三个入口，默认打开"问题库"，切换时不刷新页面。

### 1. 设置页

| 展示项 | 说明 |
|---|---|
| 平台 | DeepSeek |
| 模型 | deepseek-v4-flash |
| 接口 | Responses API |
| 联网说明 | 页面阶段为模拟状态；接入后每次监测强制使用 web_search |
| 连接状态 | 未连接 / 连接中 / 连接成功 / 连接失败 |
| API Key 输入 | 密码输入框，不得将输入内容显示到页面其他位置 |
| 按钮 | 保存并测试连接 |
| 安全提示 | API Key 仅保存在本机 Node 服务进程中，关闭服务后清除 |

模拟交互：输入任意内容后点击连接，先显示"连接中"，约 800ms 后显示"模拟连接成功"。

### 2. 问题库

每道问题包含：问题内容、目标产品、产品别名（可多个）、场景分类、优先级（核心/常规）、启用状态。

预置 5 个产品及其别名：

| 产品名 | 中文别名 | 英文别名 |
|---|---|---|
| XACDURO | 舒巴坦-杜洛巴坦 | sulbactam-durlobactam |
| Zavicefta | 头孢他啶-阿维巴坦 | ceftazidime-avibactam |
| Cresemba | 艾沙康唑 | isavuconazole |
| Vfend | 伏立康唑 | voriconazole |
| Emblaveo | 氨曲南-阿维巴坦 | aztreonam-avibactam |

预置 5 道示例问题：

1. XACDURO 在鲍曼不动杆菌感染治疗中的临床定位是什么？
2. How does Zavicefta differ from other beta-lactam antibiotics?
3. Cresemba 的用药安全性及主要注意事项有哪些？
4. Vfend compared with isavuconazole: what are the key considerations?
5. 耐药鲍曼不动杆菌感染有哪些治疗选择？

必须交互：

* 搜索问题内容
* 按产品、优先级和场景分类筛选
* 新增问题（填写产品、别名、分类和优先级）
* 删除问题（删除前确认）
* 单独启用或停用问题
* 初始状态只启用一道示例问题
* 对当前筛选结果执行全部启用或清除启用
* 显示本轮启用问题数和总调用次数（每题 3 次）
* 启动监测按钮

Excel 导入：保留下载模板和批量导入入口。如果当前阶段未实现解析，按钮给出"将在参考版本中提供"的明确提示。

### 3. 监测记录

运行历史：至少展示两条模拟运行记录（运行编号、时间、状态、问题数、调用数、进入详情入口）。

选中一道问题后展示三张独立调用卡片：

| 卡片状态 | 说明 |
|---|---|
| 等待中 | 尚未调用 |
| 调用中 | 正在等待返回 |
| 成功 | 显示模型名称、调用耗时、回答正文、web_search_call 状态、来源标题和链接（模拟阶段标记为模拟）、是否提及目标产品、匹配到的名称或别名、首次出现位置（开头/中段/末段） |
| 失败 | 显示中文错误信息和单独重试按钮 |

结果汇总：

* 成功调用数、失败调用数
* 以成功调用为分母的提及率
* 如果三次全部失败，显示"提及率暂不可用"，不得显示 0%
* 不得显示未经可靠分析的"积极、中性、消极"专业倾向标签

> "已提及"只表示回答中出现了目标产品名或预设别名，不等于 AI 推荐该产品。
> "未提及"也不代表产品不适合。

---

## Part 4：API 观察台

在监测记录中增加一个默认折叠的"API 观察台"。展开后展示：

* 本地请求地址 `POST /api/monitor`
* 上游请求地址 `POST /responses`
* 模型名称 `deepseek-v4-flash`
* 工具名称 `web_search`
* 搜索状态和来源数量
* 调用序号、监测问题、请求状态、调用耗时
* 脱敏后的简化 JSON 返回

> 观察台不得显示 API Key、Authorization 请求头或任何可复用凭证。

---

## Part 5：模拟运行行为

点击"启动监测"时：

1. 如果尚未模拟连接，提示用户先前往设置
2. 对每道启用问题创建三张"调用中"卡片
3. 使用短延时分别切换成成功或失败状态，模拟不同返回速度
4. 成功结果模拟 web_search_call: completed、回答和来源链接，明确标记为模拟
5. 使用预置回答展示已提及和未提及的差异
6. 点击失败卡片的"单独重试"，只更新该卡片

---

## Part 6：完成检查清单

* 设置、问题库、监测记录三个页面均可进入
* 页面明确区分"当前模拟"和"接入后强制联网"
* 新增、删除、搜索、筛选、启用和停用均可操作
* 学员可以自选一道预置问题或新增一道问题
* 启动监测能展示三次独立调用
* 结果能显示品牌提及、首次位置和提及率
* 结果能显示联网搜索状态和来源
* API 观察台不显示输入的 Key
* 页面在常见桌面浏览器中没有明显遮挡或溢出
