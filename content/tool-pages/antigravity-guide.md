# Google Antigravity 新手学习页

## 一句话解释

Antigravity 是 Google 推出的 AI 编程环境（Agentic IDE）。它把 Gemini 等模型和执行环境整合在一起，让 AI 不只是"给建议"，而是能直接读项目、改文件、跑命令、验证结果，是"厂家原生 Agent"的代表之一。

> **时间标注**：本文内容截至 2026 年 10 月。Antigravity 仍在快速迭代中，具体功能、可用模型和界面以官方页面为准。

## 适合谁

* 想用 Google 生态的 AI 模型完成开发任务的开发者。
* 已经熟悉 Cursor、Codex 等工具，想对比不同厂家原生 Agent 的人。
* 需要把复杂任务交给 Agent 自主执行的人。

## 不适合谁

* 完全不想接触文件、项目、代码目录的人——建议先学 Cursor 或 Trae。
* 希望 AI 一次做完所有事、自己完全不检查结果的人。
* 网络环境无法稳定访问 Google 服务的用户。

## 它能帮你做什么

| 能力 | 新手理解 | 示例任务 |
|---|---|---|
| 理解项目 | 读取整个项目并解释结构 | "这个项目的入口文件在哪里？" |
| 跨文件修改 | 一个指令同时改多个文件 | "把所有页面的标题统一成中文" |
| 自主执行 | 运行命令、查看结果、自行修正 | "运行测试，有报错就修好" |
| 生成代码 | 从需求直接生成功能 | "做一个带筛选的数据表格页面" |
| 部署辅助 | 配合 MCP 等工具完成部署 | "把这个页面部署成公开链接" |

## 使用前准备

| 准备项 | 是否必须 | 说明 |
|---|---|---|
| Google 账号 | 必须 | 用于登录和授权 |
| 一个项目文件夹 | 建议 | Agent 需要读取项目才能干活 |
| Node.js 等运行环境 | 视项目而定 | 需要运行项目时通常需要 |
| Git 版本控制 | 强烈建议 | AI 直接改文件，没有 Git 无法安全回退 |
| 稳定的网络环境 | 建议 | Google 服务在部分网络下可能不稳定 |

## 第一次使用流程

### 第一步：安装并登录

从官方渠道下载安装 Antigravity，使用 Google 账号登录，按提示完成基础设置。

### 第二步：打开项目

打开你想处理的本地项目文件夹。

### 第三步：先让 AI 理解项目

```text
请你先阅读当前项目结构，然后用新手能理解的语言解释：
1. 这个项目是做什么的
2. 主要目录分别有什么作用
3. 我应该从哪个文件开始看
4. 如果我要修改首页，应该看哪些文件
```

### 第四步：下达一个小任务

```text
请帮我完成这个小修改：[写清楚你的目标]。
要求：
1. 先告诉我你准备修改哪些文件
2. 不要一次性重构整个项目
3. 修改后说明每个文件改了什么
```

### 第五步：检查结果

AI 修改后，检查文件内容和运行结果。如果结果不对，让 AI 先解释改了什么，再决定是否回退。

## 推荐新手任务

### 任务 1：项目结构解释

```text
请用新手能理解的语言解释当前项目结构，并告诉我如果只想修改首页，应该先看哪些文件。
```

### 任务 2：修改页面文案

```text
请把页面上的"Welcome"改成"欢迎来到 Agent 学习地图"。
请先说明你会修改哪个文件，等我确认后再改。
```

### 任务 3：自主修复报错

```text
请运行项目，如果有报错，先分析原因再修复，修好后重新运行确认。
```

## 常见错误

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| 无法登录 | 网络环境问题 | 检查是否能稳定访问 Google 服务 |
| AI 改了很多文件 | 任务范围太大 | 使用"先说明改哪些文件，等我确认" |
| 修改后项目跑不起来 | 修改有副作用 | 先用 Git 回退，再把完整报错交给 AI |
| 响应缓慢 | 任务复杂或网络不稳定 | 拆分成更小的任务 |

## 和同类工具的区别

| 工具 | 更适合什么 | 注意点 |
|---|---|---|
| Antigravity | Google 原生 Agent，深度整合 Gemini | 需要稳定访问 Google 服务 |
| Cursor | 编辑器内人机协作 | 生态成熟，订阅费较高 |
| Codex | OpenAI 官方 Agent，多形态 | 需要 OpenAI 账号 |
| Claude Code | 命令行 Agent 工作流 | 对命令行要求较高 |

## 学完后下一步

1. 完成一次项目结构解释。
2. 完成一次小范围代码修改。
3. 体验一次自主修报错。
4. 学习用 Git 保存和回退修改。
5. 对比 Antigravity 与其他 Agent 工具的使用体验。
