# Lovable 新手学习页

## 一句话解释

Lovable 是一款"用自然语言做应用"的 AI 工具。你用中文描述想要什么，它直接生成一个可以打开、可以点击、可以上线的网页应用——不需要你先学会写代码。它是"Vibe Coding"（对话式编程）的代表工具之一。

> **时间标注**：本文内容截至 2026 年 10 月。Lovable 功能和定价迭代较快，具体以官方页面为准。

## 适合谁

* 完全不会写代码，但想做出一个可用小工具的人。
* 需要快速做一个活动报名页、数据展示页、内部工具原型的业务同事。
* 想体验"说需求就能生成应用"的人。
* 已经用过 AI 聊天工具，想进一步用 AI 做产品的人。

## 不适合谁

* 需要处理复杂业务逻辑、接入企业系统的正式产品开发者。
* 要求完全掌控代码结构、需要深度定制的人。
* 想把敏感业务数据交给公网工具处理的人。

## 它能帮你做什么

| 能力 | 新手理解 | 示例任务 |
|---|---|---|
| 一句话生成应用 | 描述需求，AI 直接做出页面 | "做一个活动报名表，收集姓名、科室、电话" |
| 对话式修改 | 用自然语言提修改意见 | "把主色调改成蓝色，按钮再大一点" |
| 即时预览 | 边聊边看效果 | 每次修改后立即看到页面变化 |
| 数据连接 | 支持一定程度的数据库和接口 | "把提交的数据保存下来" |
| 一键发布 | 直接生成可访问的公开链接 | 部署给同事使用 |

## 和同类工具的区别

| 工具 | 更适合什么 | 新手注意点 |
|---|---|---|
| Lovable | 非技术用户快速做出可用 Web 应用 | 复杂逻辑有上限，敏感数据要谨慎 |
| Bolt | 浏览器内直接生成和运行应用 | 偏开发者，适合有基础的人 |
| v0 | 生成 UI 组件和页面 | 更偏设计稿到代码 |
| Cursor / Trae | 在编辑器里精细控制项目 | 需要了解项目结构 |

## 第一次使用流程

### 第一步：注册并新建项目

打开 Lovable 官网，注册登录后新建一个项目。

### 第二步：用自然语言描述需求

不要只说"做个网站"，要说清楚用户、场景和功能：

```text
帮我做一个学术会议报名页，包含：
1. 会议主题和时间的标题区
2. 报名表单（姓名、医院、科室、电话、是否需要住宿）
3. 提交后显示"报名成功"提示
4. 整体风格专业、简洁，主色用深蓝色
```

### 第三步：查看并迭代

AI 生成第一版后，用自然语言提修改意见，一次只改一个点：

```text
把表单里的"电话"改成"手机号"，并且设为必填项。
```

### 第四步：测试

自己完整走一遍流程：填写表单、提交、确认提示正常、刷新后行为符合预期。

### 第五步：发布

确认无误后，使用发布功能生成公开链接，分享给同事或目标用户。

## 推荐新手任务

### 任务 1：做一个报名页

目标：体验从描述到可用的完整流程。

```text
帮我做一个活动报名页，收集姓名、单位、联系方式，
提交后显示成功提示。风格简洁专业。
```

完成标准：页面上线，能正常填写并提交。

### 任务 2：做一个简单的计算器

```text
做一个 BMI 计算器：用户输入身高和体重，点击计算后显示 BMI 数值和分类。
```

完成标准：输入数据后能得到正确结果。

### 任务 3：做一个数据展示页

```text
做一个数据展示页，包含 3 个指标卡片和 1 个柱状图，
数据先用示例数据即可。
```

完成标准：页面能正常显示卡片和图表。

## 常见错误

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| 生成的东西和预期差很远 | 需求描述太模糊 | 说清楚用户、场景、功能、风格 |
| 改了一个地方毁掉别的地方 | 一次提了太多修改 | 每次只改一个问题，改完确认再继续 |
| 上线后数据看不到 | 数据存储方式没配置 | 明确说明数据要保存到哪里 |
| 页面在手机上显示错乱 | 没有指定响应式要求 | 补充"要适配手机和电脑" |

## 安全提醒

* **不要输入敏感数据**：Lovable 属于公网工具，禁止输入患者信息、客户信息、公司未公开资料。
* **对外页面要审核**：涉及医学、合规内容的页面，上线前必须走公司审核流程。
* **注意数据存储位置**：需要保存用户数据时，先确认数据存在哪里、是否符合合规要求。
* **不要用它处理正式业务系统**：Lovable 适合做原型和轻量工具，不适合承载核心业务。

## 学完后下一步

1. 完成一个报名页或计算器。
2. 学会用精确的描述减少返工。
3. 体验一次从生成到发布的完整流程。
4. 对比 Lovable 与 Cursor / Trae 的差异，理解"生成应用"和"修改项目"的不同。
5. 把这种工具限定在原型和轻量场景，敏感和正式业务交给合规环境。
