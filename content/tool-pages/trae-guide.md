# Trae 学习指南

## 一句话解释

Trae 是由字节跳动推出的 AI IDE（集成开发环境）。它类似于 Cursor，内置了智能 Chat 问答和 Builder 自动构建双模式，深度适配中文开发环境，支持多种主流模型（包括 Claude、GPT 等系列模型，具体可用模型列表以 Trae 官方页面当前显示为准），并且提供免费额度让新手可以零成本上手。

> **时间标注**：本文内容截至 2026 年 9 月。Trae 的模型列表、功能特性和定价策略迭代较快，第一次使用时请以官方页面为准。

## 适合谁

* 想体验 AI 编程 IDE，但觉得 Cursor 订阅费较贵的初学者。
* 偏好全中文交互界面、对国内网络访问和模型速度有较高要求的本地开发者。
* 想用 Builder 模式让 AI 自动定位文件并写出代码，而不只是得到文字回答的人。
* 刚开始学习 AI 编程工作流，需要一个零成本入门环境的人。

## 首次使用流程

### 第一步：下载安装
前往 [Trae 官网](https://www.trae.ai/) 下载对应操作系统的安装包并安装。安装完成后打开软件，按页面提示完成登录和基础设置。

### 第二步：选择模型
在对话区或设置中可以切换当前使用的 AI 模型。具体可用模型以官方页面为准，通常包含多个主流模型系列。新手建议先用默认模型体验，后续对比不同模型在相同任务上的输出质量。

### 第三步：导入项目
点击菜单栏的 `File -> Open Folder`，导入你的本地静态网页项目（例如 `agent-learning-map`）。

### 第四步：开启 Builder 模式
按下快捷键 `Ctrl + I` 打开 Builder 面板。

### 第五步：自然语言开发
在输入框中输入你的修改需求：
```text
“帮我在网页顶部导航栏右侧，加一个红色的‘新版上线’气泡标徽。”
```
观察 Trae 如何自动定位文件并写出代码，在右侧点击 **Accept** 即可应用。

### 第六步：检查与回退

AI 修改代码后，你需要检查两件事：文件内容是否符合你的要求、项目运行后页面是否正常。如果结果不对，先不要继续追加更多要求，应该让 AI 解释它改了什么。

可以问：

```text
请总结你刚才修改了哪些文件、每个文件改了什么、如果我要回退应该怎么做。
```

如果你正在学习 Git，建议每次完成一个小修改后提交一次。这样出错时更容易回退。

## 常见错误

* **Chat 模式与 Builder 模式混淆**：在 Chat 窗口（Ctrl + U）输入的指令只会得到文字回答，不会自动修改文件；只有在 Builder 窗口（Ctrl + I）输入，AI 才会替你动手改代码。
* **无条件全盘接受 (Accept All)**：AI 偶尔会写出多余的测试代码，接受前务必在分屏 Diff 界面中人眼扫视一遍修改的内容。
* **任务范围太大**：一次让 AI 改太多东西，容易出乱。建议每次只给一个小而明确的任务，改完确认后再继续。

## 推荐新手任务

### 任务 1：让 Trae 解释项目结构

目标：知道项目大概由哪些部分组成。

```text
请用新手能理解的语言解释当前项目结构，并告诉我如果只想修改首页，应该先看哪些文件。
```

完成标准：AI 能指出 2-5 个关键目录或文件，并说明每个文件的用途。

### 任务 2：修改一个页面文案

目标：完成第一次低风险代码修改。

```text
请把页面上的"Welcome"改成"欢迎来到 Agent 学习地图"。
请先说明你会修改哪个文件，等我确认后再改。
```

完成标准：页面文案被修改，项目没有新增报错。

### 任务 3：用 Builder 模式添加一个简单组件

目标：体验 Builder 模式的自动构建能力。

```text
请在首页底部加一个"联系方式"区域，包含邮箱和电话。
先告诉我你准备改哪些文件，等我确认后再改。
```

完成标准：页面上出现了新的联系方式区域，布局正常。

## 推荐 Prompt

### 项目结构解释

```text
请你先阅读当前项目结构，然后用新手能理解的语言解释：
1. 这个项目是做什么的
2. 主要目录分别有什么作用
3. 我应该从哪个文件开始看
4. 如果我要修改首页，应该看哪些文件
5. 哪些文件不建议新手随便改
```

### 小范围修改

```text
请帮我完成这个小修改：[写清楚你的目标]。
要求：
1. 先告诉我你准备修改哪些文件
2. 不要一次性重构整个项目
3. 修改后说明每个文件改了什么
4. 如果有风险，请提前告诉我
```

## 防泄密安全提醒

* **云端合规性**：Trae 的云端服务通过字节跳动传输。如果你正在处理涉及外企合规合资、或敏感医药临床未盲数据，请确保上传代码上下文符合公司内部的涉密合规出境规定。
* **API Key 安全**：不要把 API Key、密码或 Token 写进项目文件并上传到公开仓库。使用 `.env` 文件保存，公开前检查是否包含密钥。
* **敏感数据不上传**：不要把未经发表的临床试验双盲数据、公司未公开的商业战略文档、或包含客户个人信息的原始文件投喂给任何 AI 工具。

## 和同类工具的区别

| 工具 | 更适合什么 | 新手注意点 |
|---|---|---|
| Cursor | 在编辑器里读代码、改代码，社区生态最大 | 订阅费较高，免费功能受限 |
| Trae | 全中文界面、Builder 模式、免费额度大 | 云端服务走字节跳动，注意合规出境 |
| Codex | OpenAI 官方 Agent，支持 IDE / 终端 / 云端三种形态 | 需要海外网络环境 |
| 普通聊天机器人 | 解释概念、写代码片段、生成思路 | 不一定能直接读取你的本地项目文件 |

## 学完后下一步

1. 从 GitHub 下载一个简单项目，用 Trae 打开。
2. 让 Trae 解释项目结构。
3. 用 Builder 模式修改一个页面文案或添加一个简单组件。
4. 学习用 Git 保存修改，确保出错时可以回退。
5. 尝试让 Trae 修复一个简单报错。

如果你能完成这些任务，就已经从"只会问 AI 问题"进入到"能用 AI 处理一个小项目"的阶段了。
