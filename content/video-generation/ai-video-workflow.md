# AI 视频生成工作流：从需求到成片

## 一句话解释

掌握从"定任务"到"包装导出"的闭环全流程，针对氛围/讲解/回顾三种场景匹配最高效的 AI 工具方案，用万能提示词公式和六个核心方法让视频生成结果更稳。

## 适合谁

* 想用 AI 视频提升学术活动预热、品牌内容和团队互动感染力的 MKT 和 DM。
* 想在医生碎片时间传递产品亮点的 MICS。
* 有想法但不知道怎么变成可生成视频结构的人。

---

## Part 1：AI 视频能为业务做什么

AI 视频的核心价值是让学术专业度与视觉冲击力结合，把常规业务素材转化为极具感染力的视听表达。

| 角色 | 应用场景 |
|---|---|
| MKT | 学术活动预热、权威发布、疾病科普——兼顾成本和质感 |
| DM | 区域会议互动更多样，团队高光时刻更具感染力 |
| MICS | 产品亮点传递和交互形式在医生碎片时间中更生动 |

## Part 2：工作流四步法

从需求到成片，先选类型，再走流程。

### 四步流程

| 步骤 | 说明 |
|---|---|
| 1. 定任务 | 明确目标，准备素材或想法 |
| 2. 出脚本/分镜 | 把想法变成可生成的结构 |
| 3. 生成视频素材 | 用 AI 工具产出核心内容 |
| 4. 包装导出 | 剪辑成片，审核发布 |

### 三种视频类型

| 类型 | 场景 | 工具路线 |
|---|---|---|
| 氛围型 | 会议暖场、活动预热、创意推广 | Chat 工具聊出画面感 → 分镜 → AI 生成 → 剪映拼接 |
| 讲解型 | 产品要点传递、医学教育 | 有素材（KV/海报/参考图）直接用 → 分镜 → AI 生成 |
| 回顾型 | 团队高光时刻、活动回顾 | 素材组合 → 分镜 → AI 生成 → 剪映配乐 |

## Part 3：万能提示词公式

提示词无需长篇大论，关键在结构清晰。

### 六要素公式

```
主体 + 动作 + 场景 + 镜头 + 风格 + 限制项
```

| 要素 | 说明 | 优先级 |
|---|---|---|
| 主体 | 是谁，或是什么核心物品 | 优先写清 |
| 动作 | 在做什么具体的动作 | 优先写清 |
| 场景 | 发生在哪里，处于什么样的环境 | - |
| 镜头 | 镜头如何运动（推、摇、特写等） | - |
| 风格 | 整体画面的视觉风格和光影氛围 | - |
| 限制 | 时长、画幅比例、不要出现什么 | - |

---

## Part 4：让结果更稳的六个核心方法

1. **一镜一意**：一个指令只做一个镜头，别让 AI 一次生成完整短片
2. **首尾帧锁定**：用首帧图和尾帧图限定每个镜头的起止画面，让 AI 在范围内生成
3. **连贯接力**：上一个镜头的尾帧 = 下一个镜头的首帧，保证画面连贯
4. **文字分离**：AI 视频工具合成文字能力差，视频只生成画面，字幕文案全部在剪映中期叠加
5. **逐步微调**：先确认第一个镜头满意，再继续做下一个，不要一次全部生成
6. **风格统一**：所有镜头使用一致的风格描述词，避免前后画面割裂

## Part 7：边界意识

### 先从小场景开始

* 先做 15-30 秒
* 先做内部场景
* 先跑通一条完整路线

### 这几条边界要记住

* 不要上传敏感个人信息
* 不要直接生成未经审核的医学结论
* 对外内容仍然要走审核

> 先想清楚需求，再选路线，再进工具；先做出第一版，后面会越来越顺手。

## 推荐 Prompt

```text
你是一个美资药企的数字化经理，服务于抗感染业务的推广赋能。
你想用 AI 生成一个 30 秒的学术会议会前暖场视频。

请不要着急生成方案，先和我讨论：
1. 核心视觉意象（科幻军事风 / 微观生物学 / 两者结合）
2. 核心价值点优先级（学术硬实力 vs 市场好消息）
3. 视频生成工具的发挥空间
4. 节奏与 BGM 的基调（澎湃震撼 vs 睿智深邃）

讨论清楚后，再给我分镜脚本和每个镜头的提示词。
```
