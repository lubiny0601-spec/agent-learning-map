# 阅读优先字体排版设计说明

## 目标

修正学习地图的中文与英文混排体验，让首页、课程卡片、章节介绍和阅读器正文具备稳定、清晰、适合长期学习的文字层级。

## 保留范围

不修改课程内容、章节顺序、背景资产、卡片入口、阅读器、搜索、进度、移动导航、构建脚本或本地进度格式。

## 字体策略

页面字体变量改为明确的中英文字体栈：

```css
--font: 'Instrument Sans', 'PingFang SC', 'Microsoft YaHei', 'Noto Sans CJK SC', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

Instrument Sans 保持英文和数字的视觉风格；中文优先使用系统 CJK 字体。为避免浏览器伪造粗体或斜体造成字形失真，页面使用 `font-synthesis: none`。

## 层级与节奏

| 位置 | 字号与字重 | 行高 | 目的 |
| --- | --- | --- | --- |
| 首页标题 `h1` | `clamp(2.35rem, 5.6vw, 4.4rem)`，700 | 1.18 | 保留首屏重点，避免中文超大轻字重显得松散 |
| 章节标题 `h2` | `clamp(1.8rem, 3.8vw, 3.2rem)`，700 | 1.22 | 让章节更易扫读 |
| 卡片与三级标题 `h3` | 1.28rem，700 | 1.35 | 稳定容纳两行中文标题 |
| 首屏与章节说明 | 1.04–1.1rem，400 | 1.75–1.8 | 提升长中文段落可读性 |
| 卡片正文 | 0.98rem，400 | 1.75 | 与标题、标签形成清晰层级 |
| 阅读器正文 | 1rem，400 | 1.85 | 适配长篇教程阅读 |
| 标签和元信息 | 0.72–0.82rem，500–700 | 1.5 | 保持紧凑且不抢正文注意力 |

中文标题采用较温和的负字距（不低于 `-.035em`）；正文不使用负字距。标题与说明、说明与卡片、卡片标题与正文之间使用一致的 8/12/16/24px 间距。

## 组件规则

- `.lead` 与 `.section-head p` 限制为适合阅读的宽度，避免在宽屏上形成过长行。
- 卡片标题、正文和底部行动提示拥有固定的纵向节奏；课程标签不改变现有可点击行为。
- 阅读器的标题与正文使用独立规则，正文不继承首页的超大标题比例。
- 现有暖白表面、春日背景、章节色签、黑绿焦点状态和 UI/UX 次级入口不改变。

## 响应式与可访问性

- 640px 以下，首页标题最大为 3.15rem，章节标题最大为 2.2rem，避免窄屏中文断行拥挤。
- 手机端正文最低维持 1rem 与 1.75 行高。
- 不把字重或颜色作为唯一信息状态；既有焦点样式和 44px 点击目标继续保留。
- `prefers-reduced-motion` 的现有规则不受影响。

## 验证标准

- 静态界面校验检查明确 CJK 字体回退、`font-synthesis: none`、标题/正文行高、移动端标题上限和阅读器正文规则。
- 项目构建、UI/UX 校验、界面校验与 Git 差异检查均通过。
- 不新增外部字体请求或运行时依赖。

## 非目标

- 不下载或内嵌新的中文字体文件。
- 不改写任何课程文案。
- 不把页面改为衬线字体或海报式强装饰排版。
