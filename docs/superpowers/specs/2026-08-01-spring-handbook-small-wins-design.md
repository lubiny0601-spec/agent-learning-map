# 春日手账学习地图与今日小成果设计说明

## 目标

在不改变已有学习内容、课程映射、搜索、阅读器、完成状态和进度存储逻辑的前提下，将学习地图统一为“春日手账感”视觉世界。首页首先回答“我今天能完成什么”，让用户在进入课程目录前看见一个明确、可完成的小成果。

## 已确认的体验方向

- 视觉语言：春日手账感；使用暖纸、低饱和草木绿、淡紫与柔黄作为识别色。
- 首页主张：今天就完成一个小成果。
- 首页结构：采用“今日小成果”任务卡，而非仅以课程分类或学习日志为第一视觉层。
- 内容边界：保留全部现有课程、标签入口、UI/UX 章节、阅读器、搜索、学习进度与导航，不新增或替换课程正文。

## 首页

### 今日小成果卡

首屏的主要行动区改为一张纸张质感的任务卡，包含：

1. 一个真实存在的学习入口对应的成果名称；
2. 预计完成时间；
3. 最多三个简短步骤；
4. “开始任务”按钮，打开当前任务所映射的既有阅读内容；
5. 与当前学习进度一致的提示，而不创建第二套完成数据。

默认任务从已有 `data-key` 课程中选择一个能在短时间内获得清晰产出的教程。任务的完成行为仍复用阅读器的既有完成状态；任务卡只读取该状态并同步显示完成反馈。

### 背景与装饰

保留原创春日草地资产作为远景，但降低其在正文区域的对比度。首屏以暖白纸张承载文字与操作，少量使用便签、圆角贴纸和叶片色块表达层次；装饰不得遮挡标题、进度和主要操作。背景加载失败时，渐变与纯色纸张仍保持完整可读性。

## 章节、卡片与标签

### 章节面板

所有学习板块改用统一的暖纸表面、细结构边线和章节色签。颜色用于识别而非填满整块背景；深色章节也统一使用纸面卡片与深色文字，避免跳出整体视觉世界。

### 课程卡片

卡片保留现有整卡入口与课程标签入口。每张卡的可扫描信息固定为：课程类型、课程标题、简短结果说明和“开始学习”操作。标签视觉上归入“学什么 / 用什么 / 产出什么”，但仍打开其所属课程，不改变现有 `data-key` 与内容映射。

卡片悬停仅上浮少量距离并强化边线；按下时使用 `scale(.96)` 的轻反馈。卡片、标签与按钮均具备可见的焦点状态，触控目标最小为 44px。

## 阅读与导航

- 阅读页采用暖纸底与舒适行宽，保持已实施的中文字体回退、行距和移动端字号规则。
- 阅读页新增一个非侵入式“下一步实践”提示，指向当前文章内已存在的操作或下一张既有课程卡；内容缺失时不显示该提示。
- 顶部导航与搜索保持原功能，只统一其边线、焦点、悬停和按压状态。
- 小屏幕下采用单列卡片与折叠导航，章节色与背景固定而非视差滚动。

## 交互、可访问性与动效

- 所有改变均使用既有原生 HTML、CSS 与 JavaScript，不引入框架或第三方运行时依赖。
- 不使用 `transition: all`；仅过渡 `transform`、`background-color`、`border-color`、`box-shadow` 与 `color`。
- `prefers-reduced-motion: reduce` 下禁用视差、上浮与按压动画，并保留颜色和边线等静态反馈。
- 每个可操作对象提供鼠标、触控和键盘路径；焦点轮廓的对比度足够且不被卡片覆盖层遮挡。

## 实施边界

- 主要修改 `prototype/index.html` 中的视觉令牌、首页结构、卡片样式与交互初始化；必要时扩充现有界面校验脚本。
- 不修改 `content/` 中的课程正文，不变更构建管道或本地存储键。
- 不复制外部品牌、Logo、原文案或专属视觉资产。

## 验证标准

1. `npm run build` 能重新同步内容且不覆盖视觉和交互增强。
2. `npm run verify:uiux` 与 `npm run verify:interface` 均通过；后者新增任务卡、可点击课程入口、最小触控面积与减少动效规则的检查。
3. 首屏“开始任务”可打开映射课程；课程完成状态能在首屏任务卡中同步反馈。
4. 任意课程卡的整卡入口、标签入口、键盘焦点和阅读器均正常工作。
5. 在窄屏下，导航、首屏任务卡和课程入口没有横向溢出，且触控区域不小于 44px。
6. 完成后的界面运行机械设计检查与桌面、移动端各一次人工视觉检查；不遗留无用样式或临时素材。
